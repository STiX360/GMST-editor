# Changelog

## 0.4.0

- Edit all loaded numeric and string GMSTs through native OpenMW Scripts settings.
- Group additional records by topic or alphabetical text/asset ranges, with exact identifiers and types.
- Save edits independently of saves and apply them on a full OpenMW relaunch.
- Reset to the current modlist baseline rather than hardcoded vanilla values.
- Preserve existing editor settings and provide per-row Reset and an application toggle.

Requires OpenMW 0.52. Verified with 0.52.0. Live runtime GMST changes are not supported.
